# vite-et-gourmand 🍽️
Application web de commande de menus traiteur pour l'entreprise Vite & Gourmand, basée à Bordeaux.
## Stack technique

- **Front** : HTML5, CSS3, JavaScript
- **Back** : PHP 8 avec PDO
- **Base de données relationnelle** : MySQL
- **Base de données NoSQL** : MongoDB
- **Déploiement** : fly.io
